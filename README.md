Open `index.html` in your browser. Edit content in `index.html`, styling in `styles.css` and the footer-year helper in `script.js`.

## GitHub Pages
This repository is prepared for https://Sabelo153.github.io.
In Settings → Pages, select Deploy from a branch, main and /(root).

The portfolio is static. Sentinel's PHP/API/database runs separately and is not deployed by this repository.
